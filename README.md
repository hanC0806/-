# 서울 기후 분석 대시보드

서울 기온 CSV를 활용해 추세, 월별 분포, 계절별 특성, 극값 기록, 일교차를 탐색하는 Streamlit 웹앱입니다.

## 프로젝트 구조

```text
seoul-climate-analysis/
├── app.py
├── requirements.txt
├── seoul_temperature.csv
└── README.md
```

`seoul_temperature.csv`는 직접 준비해 메인 코드와 같은 폴더에 넣거나, 실행 후 사이드바에서 업로드하세요.

## 제공 기능

1. **추세선 분석**: 연도별 평균기온과 5년 이동평균
2. **월별 히트맵**: 연도·월별 평균기온 분포
3. **계절 분석**: 봄·여름·가을·겨울의 평균/최고/최저 기온 및 일별 평균기온 분포
4. **기록 조회**: 가장 더운 날, 가장 추운 날 등 기온 기록과 CSV 다운로드
5. **일교차 분석**: 일별 및 연도별 평균 일교차, 최대/최소 일교차 기록
6. **연도 범위 슬라이더**: 모든 분석에 적용되는 기간 필터
7. **데이터 정리**: 날짜 앞뒤의 탭/공백 제거, 날짜 파싱, 기온 값 숫자 변환, 필수 날짜/기온 결측 행 제거

## CSV 형식

필수 컬럼 이름은 다음과 같아야 합니다.

- `날짜`
- `지점`
- `평균기온(℃)`
- `최저기온(℃)`
- `최고기온(℃)`

날짜 값에 `\t1907-10-01`처럼 탭 문자가 포함되어도 `strip()`으로 정리합니다. 날짜 변환에 실패하거나 날짜 및 기온 컬럼에 결측치가 있는 행은 분석에서 제외합니다. `지점` 컬럼은 입력 CSV의 형식 확인에 사용되며, 분석은 기온 컬럼 기준으로 진행합니다.

## 설치 및 실행

Python 3.9 이상을 권장합니다.

### 1. 가상환경 생성 (선택)

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 3. 대시보드 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시된 Local URL을 여세요.

## 참고 사항

- 연도별 통계는 각 연도의 유효한 일별 관측치로 계산합니다.
- 5년 이동평균은 연도별 평균기온 시계열의 최근 5개 행을 기준으로 계산합니다. 데이터가 없는 연도가 있다면 관측된 연도 행 기준으로 계산됩니다.
- 계절은 기상학적 월 기준으로 봄(3–5월), 여름(6–8월), 가을(9–11월), 겨울(12–2월)로 구분합니다.
- 기록 조회에서 내려받는 CSV는 선택 기간 및 기록 종류에 따라 필터링된 결과입니다.
